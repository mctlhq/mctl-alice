Возможности

Все ключевые сценарии взаимодействия с голосовым помощником Алиса в виде стандартных инструментов MCP.

Симуляция голосовых команд

Выполнение любых команд текстом ровно так, как если бы вы произнесли их вслух в микрофон колонки: «Включи джаз», «Какая погода завтра», «Выключи свет везде».

Произвольная речь (TTS)

Озвучивание любого произвольного текста через выбранную колонку. Идеально для голосовых уведомлений, напоминаний, утренних сводок и ответов ассистента.

Управление громкостью

Точная регулировка громкости от 1 до 10 для конкретной колонки, комнаты или устройства по умолчанию.

Управление медиа-плеером

Пауза, возобновление проигрывания, остановка трека, переключение на следующий или предыдущий трек в Яндекс Музыке.

Обнаружение умного дома

Автоматическое получение списка всех колонок, комнат, групп и умных устройств пользователя с информацией об их возможностях.

Сценарии автоматизации

Мгновенный триггер настроенных сценариев умного дома Яндекса по их названию или идентификатору («Доброе утро», «Ушел из дома», «Кино»).

Инструменты MCP

Набор инструментов, регистрируемых сервером mctl-alice. AI-ассистент вызывает их автоматически в диалоге.

Инструмент Назначение Параметры Действие
alice_list_devices Список всех колонок, комнат и умных устройств. only_speakers?: boolean чтение
alice_send_command Выполнение голосовой команды текстом (прямая симуляция речи). command: string, device?: string управление
alice_say_phrase Синтез произвольной речи через колонку (TTS-сообщения). phrase: string, device?: string управление
alice_set_volume Установка громкости от 1 до 10. level: number (1-10), device?: string управление
alice_media_control Управление плеером: play, pause, stop, next, prev. action: string, device?: string управление
alice_trigger_scenario Запуск сценария умного дома по названию или ID. scenario: string сценарий

Примеры запросов к ассистенту

После подключения просто общайтесь с вашим AI-ассистентом на естественном языке.

  • «Какие колонки Алиса у меня есть и в каких комнатах?» — ассистент вызывает alice_list_devices и показывает список с именами и расположением.
  • «Включи джаз на колонке в гостиной» — ассистент симулирует голосовую команду для станции в гостиной через alice_send_command.
  • «Сделай громкость 4 на кухне» — alice_set_volume меняет громкость целевого устройства.
  • «Скажи через колонку в детской, что пора обедать» — alice_say_phrase синтезирует речь через нужную станцию.
  • «Поставь музыку на паузу» — alice_media_control приостанавливает текущее воспроизведение.
  • «Запусти сценарий Спокойной ночи» — alice_trigger_scenario активирует вечернюю автоматизацию.

Как подключить

Три простых шага для подключения к вашим любимым AI-клиентам.

  1. Шаг 1. Добавьте коннектор в вашего AI-ассистента:
    Используйте публичный эндпоинт: https://alice.mctl.ai/mcp

    • Claude.ai: перейдите в Customize → Connectors → “+” → Add custom connector, вставьте URL https://alice.mctl.ai/mcp (или SSE: https://alice.mctl.ai/sse) и нажмите Add.

    • ChatGPT: откройте Settings → Apps & Connectors → Advanced settings → Developer mode, затем в Apps & Connectors → Create укажите URL https://alice.mctl.ai/mcp. Сервер поддерживает RFC 8414 & OAuth 2.1 — ChatGPT автоматически проведет вас через авторизацию в Яндексе.

    Другие клиенты, пошаговый сценарий и как отозвать доступ →
  2. Шаг 2. Авторизуйтесь в Яндексе (OAuth):
    При подключении через ChatGPT или Claude.ai окно авторизации Яндекса откроется автоматически. Вы также можете выполнить вход заранее на странице /auth/login. Это свяжет ваш токен управления умным домом с сессией MCP.
  3. Шаг 3 (Опционально). Настройте Quasar Cookie для динамического TTS:
    Официальный API Умного дома Яндекса управляет устройствами и запускает сценарии. Для синтеза речи (TTS) и произвольных текстовых команд подключите неофициальный Quasar API на странице /auth/cookie: он использует вашу веб-сессию Яндекса.

Частые вопросы

Безопасно ли подключать умный дом через mctl-alice?

Вход идёт через OAuth 2.1 с PKCE. Токены Яндекса хранятся зашифрованными (AES-256-GCM), а токены ИИ-клиентов — только в виде хешей. Устройствами умного дома сервис управляет через официальный API Умного дома Яндекса. Синтез речи и текстовые команды на колонках работают через Quasar — неофициальный API веб-интерфейса Яндекса. Он подключается только по вашему желанию и может перестать работать без предупреждения.

Какие модели колонок Яндекс Станция поддерживаются?

Поддерживаются все актуальные модели: Яндекс Станция Макс, Станция Миди, Станция 2, Станция Лайт, Станция Мини, Станция Дуо Макс, а также сторонние устройства с поддержкой голосового помощника Алиса.

В чем разница между IoT API и Quasar API?

API Умного дома Яндекса — официальный и документированный: он показывает устройства, их состояние и сценарии и управляет ими. Quasar — неофициальный внутренний API, которым пользуется веб-интерфейс Яндекса. Для него нужна ваша веб-сессия Яндекса, и через него работают синтез речи (TTS) и текстовые команды. Яндекс не поддерживает Quasar для сторонних сервисов, а сессия даёт доступ шире, чем OAuth, поэтому подключайте его только если вам нужны эти функции.

Можно ли управлять устройствами умного дома других брендов?

Да! Любое устройство (лампочки, розетки, реле, роботы-пылесосы, кондиционеры), привязанное к вашему умному дому в приложении «Дом с Алисой», доступно для симуляции команд и запуска через сценарии.
